# OttoPet
An inspiration from BV1Vu41177QE, https://www.bilibili.com/video/BV1Vu41177QE, a virtual desktop pet of the esports streamer Electric Stick Otto's meme-style antics.

## Core Features:
[Desktop Pet]
[Ai Chat]

## How to Operate:
- Left-click the mouse to immediately play the voiceover
- Right-click menu: Buy food with Otto Coins to feed, earn coins by livestream work, AiChat conversation, exit, etc.
- When AiChat replies match common phrases, it automatically plays the corresponding voiceover

## System Requirements:
Windows 7
